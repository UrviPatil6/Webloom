# 🌿 Webloom

**A collection of tools for generating and indexing web pages.**

## What's inside

- **[page generator](./page%20generator)** — MERN app that generates WordPress pages with AI-written content and publishes them automatically.
- **[page-link-indexer-v3](./page-link-indexer-v3)** — Gets URLs indexed across Google, Bing, Yandex, and more within an hour using 9 parallel strategies.

## Quick start

Each project has its own setup — see the README inside its folder.

```bash
cd "page generator" && npm run install-all && npm run dev
cd page-link-indexer-v3 && npm install && npm start
```
